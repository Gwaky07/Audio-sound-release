# 中文口播删词：边界残留与接缝修复

适用于删除口播中的单字、口头禅、整句或整段，以及用户反馈“删完有残留”“接缝杂音”“卡一下”“突然接上下一句/一个字”的场景。

这不是普通降噪问题。时间码只是候选范围；最终删词必须以局部语音边界、接缝方式和语义停顿共同决定。

## 一、触发与输入

以下任一情况必须进入本流程：

- 用户要求删除指定口播、句子、口头禅或片段。
- 用户给出原视频与旧处理视频，指出删词后有尾音、爆点、静音断层或突然续接。
- 用户说“边界残留”“接缝杂音”“卡一下”“突然接上下一句/一个字”。

优先取得：原素材、目标删除文本、时间码、以及有问题的旧版。若时间码来自长视频而当前素材是局部示例，先将其换算为局部时间；不得把长视频时间码直接用于局部片段。

## 二、先定位，不要直接重剪

1. 用 `ffprobe` 检查原版和旧版的时长、帧率、音轨采样率。
2. 对原版与旧版各提取单声道 WAV；比较接缝前后约 0.3–1.0 秒的波形与频谱。
3. 若旧版与原版是同一片段的不同剪辑，使用局部相关性或 MFCC/DTW 对齐，反推旧版真正跳过的原片范围。不要因文档写了“01:27–01:29”就假设局部文件也在 87–89 秒。
4. 先判定问题类型：
   - **残留尾音**：删前一侧仍保留目标句的尾部音素。
   - **硬接缝/爆点**：波形在接点附近突然跳变。
   - **静音断层**：残留尾音后突然归零，再突然出现下一句。
   - **语义续接过急**：没有爆点，但两个不同音素直接重叠，听起来像“突然接上一个字”。

## 三、默认删词命令

使用仓库脚本，不要临时拼接 `ffmpeg` 管道：

```powershell
python scripts/remove_spoken_segments.py run "<原视频或音频>" `
  --cut "<开始>,<结束>" `
  --removed-phrase "<删除文本>"
```

默认行为：

- `--boundary-search-ms 80`：删除起点仅向前、终点仅向后寻找最近低能量边界；没有可靠安静谷时不移动，避免吞掉保留语音。
- `--crossfade-ms 12`：普通接缝的短等功率交叉淡化；它用于防爆点，**不能**作为清除残留或修复语义节奏的主要手段。
- 视频会按真实交叉淡化帧数同步补偿，避免多次删除后音画累计漂移。

## 四、语义续接过急：启用语音安全接缝

如果普通交叉淡化后仍出现“后面卡一下”“下一句/一个字突然接上”，不要继续加长 `--crossfade-ms`。长交叉淡化会叠加两个不同音素，反而更像吞字或卡顿。

改用语音安全接缝：

```powershell
python scripts/remove_spoken_segments.py run "<原视频或音频>" `
  --cut "<开始>,<结束>" `
  --removed-phrase "<删除文本>" `
  --seam-pause-ms 80
```

其行为是：

1. 保留前一句末尾并独立淡出。
2. 保留下一句开头并独立淡入。
3. 中间插入短微停顿；视频冻结上一帧相同时长。

调参原则：

- 先试 `60–100ms`，中文讲解默认从 `80ms` 开始。
- `45ms` 仅适合原本语速很快的连续短句。
- `120ms` 以上容易显得人为拖拍，除非原说话人本来有明显停顿。
- `--seam-pause-ms` 默认是 `0`，不要对所有删词批量启用；仅在已复核的语义接缝使用。

## 五、精修顺序

1. **残留尾音**：先把请求的开始点向前微调 `20–80ms`，再运行边界搜索；不要先拉长淡化。
2. **吞掉起字**：将请求结束点回退到下一句起字之前；不要让自动搜索跨过下一句寻找更深的低能量谷。
3. **硬接缝**：保留 `12ms` 或更短的交叉淡化；先检查是否仍切在高能量音素中间。
4. **突然续接**：使用 `--seam-pause-ms 60–100`，不要混叠不同音节。
5. 每次只改一个接缝；重导出 WAV、MP3、MP4 后再继续下一个。

## 六、必须验证

每个删词接缝都必须完成以下检查后才能交付：

- 报告中的 `requested_cuts` 与 `cuts`：确认自动收边没有超出可接受范围。
- `crossfade_frames`：普通交叉淡化应为正数；语音安全接缝应为 `0`。
- `seam_pause_frames`：仅使用 `--seam-pause-ms` 时应为正数。
- 局部频谱和波形：检查接缝前后至少各 `0.3–0.5s`。
- 旧版存在的“残留音素 → 突然静音 → 下一句”的断层，应替换为平滑淡出、可控微停顿、平滑淡入。
- WAV 与 MP4 时长差必须小于一帧时长；不能只检查最终文件能播放。
- 重新导出 MP3，并确认成品在 `output/修音成品/` 下，命名遵守 `修音版_<原名>` 与 `_01/_02` 递增规则。

## 七、不得做的事

- 不要仅因脚本运行成功就判定删词成功。
- 不要把长时间码直接复用到局部示例视频。
- 不要用更长交叉淡化掩盖残留音素或语义卡顿。
- 不要为消除残留而盲目把结束点向后扩到下一句内部。
- 不要在未看局部频谱/波形和报告字段的情况下声明“接缝已解决”。
